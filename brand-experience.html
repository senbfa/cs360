Colours

Every colour token in the system, grouped by role. Use the swatch for a picker, type an exact hex for brand compliance, and read the live specimen to see how the value behaves in context. Contrast ratios are computed against the surface each token actually renders on.

Logo

The single mark that has to look right on every channel. The logo is a real <img> on each page rather than a colour/size token, so it doesn't go through the usual Apply/Export flow — pointing it at a new path here generates a small script that rewrites every page for you.

Accessibility

WCAG 2.1 contrast audit across every foreground/background pairing the app actually renders. UK and US banks are held to WCAG 2.1 AA, so anything below 4.5:1 for body text (3:1 for large text and UI boundaries) is flagged.
