Momentum Formula

12M Return = Current Price / Price 252 trading days ago − 1
6M Return = Current Price / Price 126 trading days ago − 1
Daily Log Return = ln(Pt / Pt−1)
Annual Volatility = StdDev(Daily Log Returns) × √252

12M Momentum Ratio = 12M Return / Volatility
6M Momentum Ratio = 6M Return / Volatility

Z12 = (MR12 − Mean(MR12)) / StdDev(MR12)
Z6 = (MR6 − Mean(MR6)) / StdDev(MR6)

Final Momentum Score = 0.50 × Z12 + 0.50 × Z6

How to read the scanner

12M Return: Longer-term price momentum.
6M Return: Medium-term momentum.
Volatility: One-year annualised standard deviation of daily log returns.
MR12 / MR6: Return divided by volatility. Higher is better.
Z12 / Z6: Cross-sectional standardised momentum scores.
Momentum Score: 50% 12-month risk-adjusted momentum + 50% 6-month risk-adjusted momentum.
